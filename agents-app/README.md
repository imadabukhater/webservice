# تطبيق الوكلاء

تطبيق للهاتف (PWA يُثبَّت من المتصفح على الشاشة الرئيسية) مع خادم خاص به.
لكل وكيل اسم مستخدم وكلمة مرور، والمدير يتحكم بكل شيء.

## الصلاحيات

| | المدير | الوكيل |
|---|---|---|
| إضافة/تعديل/إيقاف/حذف وكيل، تعيين اسم المستخدم وكلمة المرور | ✔ | |
| شحن/خصم/تعيين رصيد الوكيل، نقل رصيد بين وكيلين | ✔ | |
| الشركات والباقات (التكلفة والسعر الافتراضي) | ✔ | |
| **سعر خاص لكل وكيل لكل باقة** | ✔ | يرى سعره فقط، ولا يرى التكلفة |
| **العروض**: إضافة عرض بسعر خاص وتاريخ بداية ونهاية | ✔ | يرى العروض السارية ويفعّل بها |
| تفعيل رقم (يُخصم السعر من رصيد الوكيل) | ✔ لأي وكيل | ✔ من رصيده |
| تجميد / إلغاء تجميد / تبديل الشريحة / فصل الرقم | ✔ | ✔ لأرقامه فقط |
| نقل رقم من وكيل إلى آخر، حذف رقم | ✔ | |
| سجل العمليات (الرصيد قبل وبعد، التكلفة، الربح) | ✔ الكل مع الربح | سجله فقط بدون التكلفة |

كل التحقق (الصلاحيات، كفاية الرصيد، السعر) يتم في الخادم، فلا يستطيع الوكيل تغيير سعره أو رصيده.

## التشغيل

يحتاج Node.js 22.13 أو أحدث. لا توجد مكتبات لتثبيتها.

```bash
cd agents-app
ADMIN_USERNAME=admin ADMIN_PASSWORD='كلمة-مرور-قوية' npm start
# افتح http://localhost:3000
```

- في أول تشغيل يُنشأ حساب المدير من `ADMIN_USERNAME` و`ADMIN_PASSWORD`.
  بدون `ADMIN_PASSWORD` تُولَّد كلمة مرور وتُطبع في سجل الخادم.
- تُحفظ البيانات في `data/agents.db` (غيّر المسار بـ `DB_FILE`). انسخ هذا الملف احتياطياً بانتظام.
- تبدأ قاعدة البيانات بشركات سلكوم وبارتنر وبيلفون وهوت موبايل وباقات سلكوم 500/300/100 جيجا.
  الباقة التي سعرها صفر لا تظهر للوكلاء حتى تحدد سعرها.

### بـ Docker

```bash
docker build -t agents-app .
docker run -d -p 3000:3000 -v agents-data:/data -e ADMIN_PASSWORD='كلمة-مرور-قوية' agents-app
```

## النشر على الإنترنت

ليستعمله الوكلاء من هواتفهم يجب تشغيل الخادم على استضافة بعنوان **HTTPS**
(مثل Render أو Railway أو Fly.io أو أي VPS)، مع قرص دائم لملف قاعدة البيانات.
بعدها يفتح الوكيل الرابط في Chrome (أندرويد) أو Safari (آيفون) ويختار
«إضافة إلى الشاشة الرئيسية»، فيعمل كتطبيق مستقل بأيقونته.
