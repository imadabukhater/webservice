# لوحة الوكلاء

صفحة واحدة (HTML + JavaScript بدون مكتبات) لإدارة وكلاء بيع الخطوط:

- **الوكلاء**: إضافة، تعديل، حذف، شحن/خصم/تعيين الرصيد، نقل رصيد بين وكيلين.
- **تفعيل خط**: اختيار الوكيل والشركة والباقة ورقم الخط؛ يُخصم سعر البيع من رصيد الوكيل وتُسجَّل التكلفة والربح.
- **الأرقام**: قائمة الأرقام المفعّلة، نقل رقم من وكيل إلى آخر (مع نقل قيمته اختيارياً)، إلغاء خط مع إرجاع المبلغ اختيارياً.
- **الباقات والشركات**: إضافة وحذف وتعديل الشركات والباقات (التكلفة وسعر البيع).
- **سجل العمليات**: الرصيد قبل العملية، المبلغ، الرصيد بعد العملية، التكلفة، الربح.

## التشغيل

افتح `index.html` في المتصفح. خارج claude.ai تُحفظ البيانات في `localStorage` لهذا المتصفح فقط،
وتبدأ بشركات سلكوم وبارتنر وبيلفون وهوت موبايل وباقات سلكوم 500/300/100 جيجا بأسعار صفر لتعبئتها.

عند نشرها كـ Artifact على claude.ai مع قدرة `db` تُحفظ البيانات على الخادم وتظهر من أي جهاز.
